# KIKO – Smart Commerce Platform

## Vision

KIKO est une plateforme de commerce intelligent destinée aux commerces de détail et de gros en Afrique.

## Stack Technique

- **Frontend:** Angular 22 + Standalone Components + Tailwind CSS
- **Backend:** Spring Boot 3.5 + Spring Security + JWT
- **Database:** PostgreSQL 17

## Quick Start

```bash
# Start services
docker-compose up -d

# Backend
cd backend && ./mvnw spring-boot:run

# Frontend
cd frontend && npm install && ng serve
```

Access at http://localhost:4200
